# SO FRES# LUXURY — Online Fashion Store

A modern, high-converting, and fully responsive e-commerce web application built for a luxury fashion brand. Features an interactive product catalog, custom shopping cart mechanics, and seamless direct-to-WhatsApp order placement.

---

## 🌟 Key Features

- **Responsive Design**: Optimized for mobile, tablet, and desktop screens.
- **Product Showcase**: High-resolution gallery displaying apparel, footwear, and accessories.
- **Interactive Shopping Cart**: Add items, update quantities, and calculate sub-totals dynamically.
- **WhatsApp Checkout Integration**: Automatically formats customer orders and redirects them directly to the seller's WhatsApp with full order details.
- **Modern UI/UX**: Built with clean layouts, custom color accents, and smooth hover effects.

---

## 🛠️ Tech Stack

- **Structure**: HTML5
- **Styling**: CSS3, Bootstrap 5
- **Scripting**: JavaScript (ES6+)
- **Version Control**: Git & GitHub
